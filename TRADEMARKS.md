# Satin trademark policy

The code is MIT-licensed. The Satin name and logo are not: they identify this project, and the MIT License grants no trademark rights.

## What you can do without asking

- Say truthfully that your app is built with Satin, in its description, its About screen or its Acknowledgements. Credit is optional.
- Refer to Satin by name when you write about it, compare it or teach it.
- State where a fork came from, for example "based on Satin".

## What needs a different name

If you distribute a modified version of Satin, give it its own name and logo. Don't suggest that it is the original project, or that the Satin authors make, maintain or endorse it.

## Everything else

Any other use of the Satin name or logo needs permission from the project owner. Open an issue to ask.

## Apple

Use Apple's product names only to describe things accurately. Don't use Apple artwork or bundle Apple fonts; Satin uses the system font the user's device provides.
