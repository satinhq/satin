# dumbbell

Files: `dumbbell.svg` (outline), `dumbbell.fill.svg` (fill).

Authorship: drawn 2026-10-04 by a Claude agent (Opus 5.5) for Satin, clean-room. Revised on 2026-10-04 from written feedback. Sources were a written description of the everyday object and the visual language of Framework7 Icons 5.0.5 (MIT): 56-unit viewBox, ~3.8-unit regular stroke measured from Framework7 house / list_bullet / circle, round caps and joins, rounded corners, and fill variants made by knocking out interior detail.

Written description: A horizontal handheld dumbbell: a long open grip bar joining two equal weighted ends. Each end is a tall main plate, then a 3.4-unit gap the bar shows through, then a short solid end plate, so plates stay visibly separate from each other and from the grip down to 17 px. Outline: main plates hollow (bar does not run through them), end plates solid. Fill: all plates solid.

Method: geometry authored as primitive strokes and shapes, expanded and unioned with skia-pathops into one nonzero filled path (holes wound opposite), coordinates at 4 decimals, centred near (28,28). Not scaled up for apparent size; set-wide sizing is calibrated in the Symbol system.

Provenance: no SF Symbols file, font, image, screenshot or exported path was opened, traced or recalled for this glyph. Only Framework7 Icons SVGs were viewed, as style references.
